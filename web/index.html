airlift

Optical file transfer out of an air-gapped machine.

A beam shows a file as an animated QR loop; a phone relays what it sees to this tower, which reassembles, verifies and serves it. Nothing crosses the gap but light.

How it works

  1. 1BeamOn the air-gapped machine, airlift beam ./repo writes one offline HTML page that plays the file as a QR loop.
  2. 2ScanCreate a session here, open its link on a phone, tap Scan a beam and point the camera at the screen.
  3. 3ReceiveThe tower reassembles the chunks, verifies the sha256 chain, unpacks a repobundle and serves the download.
